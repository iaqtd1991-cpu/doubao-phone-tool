# 豆包家庭陪伴手机工具

这是一个手机可直接访问的网页工具，不需要微信开发者工具。部署到公网 HTTPS 后，手机可以单独联网使用，并支持打开摄像头做作业视频监督。

## 使用方法

1. 电脑和手机连接同一个 Wi-Fi。
2. 双击 `启动手机工具.bat`，或在当前目录运行：

```powershell
node .\server.js
```

3. 手机浏览器或微信里打开：

```text
http://电脑IP:8790
```

当前电脑检测到的 Wi-Fi IP 如果是 `192.168.101.226`，手机访问：

```text
http://192.168.101.226:8790
```

## 接入豆包

不配置 Key 时，工具会使用本地备用回复。要启用豆包真实回复，在启动前设置：

```powershell
$env:ARK_API_KEY="你的火山方舟 API Key"
$env:ARK_MODEL="doubao-seed-2-1-pro-260628"
node .\server.js
```

## 功能

- 作业监督：计时、拍照、观察记录、家长话术。
- 视频监督：手机开摄像头，截图给豆包视觉模型分析作业状态。
- 视频语音沟通：开着摄像头说话，工具会识别语音、截取当前画面、让豆包结合画面回复，并用语音播报。
- 开车陪聊：轻松话题、防困提醒、短句回复。
- 今日报告：汇总作业和车聊记录。
- 可添加到手机主屏幕，像 App 一样打开。

## 手机单独联网使用

手机摄像头权限要求 HTTPS，所以正式使用需要部署到公网 HTTPS 域名。推荐任一方式：

### 方式 A：部署到 Render

1. 把本目录上传到 GitHub 仓库。
2. 打开 Render，创建 Web Service，选择这个仓库。
3. Build Command 填：

```text
npm install --omit=dev
```

4. Start Command 填：

```text
npm start
```

5. Environment 里设置：

```text
ARK_API_KEY=你的火山方舟 API Key
ARK_MODEL=doubao-seed-2-1-pro-260628
ARK_VISION_MODEL=doubao-seed-2-1-pro-260628
```

6. 部署完成后，手机打开 Render 给你的 `https://...onrender.com` 地址。

### 方式 B：部署到自己的服务器

服务器安装 Node.js 20 以上，然后运行：

```bash
export ARK_API_KEY="你的火山方舟 API Key"
export ARK_MODEL="doubao-seed-2-1-pro-260628"
npm start
```

再用 Nginx/Caddy 配置 HTTPS 反向代理到本服务端口。

## 视频使用说明

1. 手机打开 HTTPS 地址。
2. 进入“作业”页。
3. 点击“开视频”，允许摄像头权限。
4. 把作业本放在画面里。
5. 点击“截图分析”，豆包会根据当前画面给家长监督建议。

## 视频语音沟通

1. 手机打开 HTTPS 地址。
2. 进入“作业”页。
3. 点击“开视频”，允许摄像头权限。
4. 打开“AI 语音播报”。
5. 点击“语音问豆包”，允许麦克风权限。
6. 对手机说话，例如：

```text
你看一下孩子现在有没有在认真写？
```

7. 工具会把语音转成文字，并截取当前视频画面发给豆包。
8. 豆包回复后，手机会自动语音播报。

如果打开“连续语音对话”，每次豆包回复完后，会自动继续听下一句话。不同手机浏览器对连续语音支持不同；安卓 Chrome 通常支持更好，部分微信内置浏览器或 iOS 浏览器可能需要反复点击按钮。

驾驶场景不建议开视频。开车时应使用车载蓝牙语音播报，工具只提供短句陪聊。
